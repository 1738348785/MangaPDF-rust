# ⚡ MangaPDF - 漫画与图片打包工具 (带GUI)

一个基于 Rust 开发的现代化、超轻量、极速漫画与图片转 PDF 桌面图形界面工具。

---

## 🎨 界面与核心特性

- 🖥️ **现代化图形界面 (GUI)**：
  - 对标专业漫画打包软件布局，支持浅色 / 深色（Light / Dark）主题。
  - 原生加载 Windows 系统微软雅黑中文字体，界面美观高雅。
- ⚡ **原生原画无损直存 (100% 原始画质)**：
  - **JPEG 零解码零拷贝直通**：直接提取原始 DCT 数据流写入 PDF，无任何二次重编码，微秒级极速打包，并自动兼容 CMYK 与 EXIF 方向信息。
  - **PNG 原生无损保留**：原生提取像素流并通过 Flate 压缩封装，杜绝任何有损压缩，100% 还原原始画质。
- 🚀 **全链路异步多核加速 (Rayon Multi-Core)**：
  - **后台异步丝滑导入**：扫描大型文件夹与解压 `.zip` / `.cbz` 归档均在后台分批并发执行，按需读取归档字节，彻底告别界面假死与内存堆积；
  - **分批并发转码打包**：跑满 CPU 全部多核并发性能，同时严控内存峰值，杜绝爆内存崩溃。
- 📊 **细粒度实时进度追踪与动画**：
  - 导入与打包全流程原子级进度追踪，实时展示正在处理的图片文件名与完成百分比，60 FPS 流畅动画。
- 📑 **多序列分卷管理 (Multi-Sequence)**：
  - 支持同时管理多个分卷/分话（例如同时处理第 01 卷、第 02 卷），支持独立配置、重名自动防覆盖与一键批量打包全部。
- 🖼️ **全方位文件导入与灵动拖拽**：
  - 支持单张/多张图片、漫画文件夹、以及 `.zip` / `.cbz` 压缩包直接拖入窗口、点击选择或直接拖拽到 `.exe` 图标启动；
  - 拖拽悬停时窗口边框与卡片灵动高亮响应，绝不遮挡操作界面。
- 🔢 **智能自然语义排序 (Natural Sorting)**：
  - 完美解决 `1.jpg`、`2.jpg`、`10.jpg` 变成 `1 -> 10 -> 2` 的倒序混乱问题，保证漫画阅读顺序 100% 正确。
- 🔍 **高清画廊式大图预览与翻页查看**：
  - 点击缩略图或预览按钮即可弹出高清原图（支持最高 8192px 超长条漫清晰渲染），支持窗口自适应与 100% 原始尺寸查看；
  - 键盘 `←` / `→` 无缝切页漫游，浮窗支持随意拖拽与自由调整尺寸。
- 🖼️ **可视化缩略图网格与快捷调序**：
  - 自动为所有图片生成轻量预览缩略图，支持单页前移、后移、删除、一键自然重排，以及**右键菜单一键移至第一页（设为封面）/ 最后一页**。
- 📐 **自适应页面比例与日漫右翻跨页支持**：
  - PDF 页面自动与每张图片的分辨率等比贴合，彻底消除留白与黑边；支持边距调节、A4 页面适应、统一宽度，以及可选的**日漫右翻跨页模式 (`TwoPageRight` + `R2L`)**。
- 🪶 **单文件绿色免安装**：
  - 编译后仅为单个独立的 `MangaPDF.exe`（仅约 5.7 MB），内嵌高清透明图标，不附带任何额外动态链接库或安装包。

---

## 🚀 启动与使用

### 方式 1：直接双击运行
直接双击桌面 `pdf tool` 文件夹中的 **`MangaPDF.exe`** 即可启动图形界面！

### 方式 2：一键拖拽
直接将任意漫画文件夹、`.zip` 或 `.cbz` 漫画归档拖拽到 `MangaPDF.exe` 图标上。

---

## 🛠️ 自行编译源码

如果对源码进行了修改，直接双击运行 `build.bat` 或在终端运行：
```powershell
cargo build --release
```
编译产物位于 `target/release/pdf_tool.exe`。
